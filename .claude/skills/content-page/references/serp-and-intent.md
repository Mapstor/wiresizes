# Phase 1 — SERP + intent audit procedure

Run before writing, for the primary keyword (and spot-check the top
secondary). KWP told you what people want and how they phrase it; the SERP
tells you what format Google rewards. Chat-side web search is not a perfect
SERP mirror — where feature presence is decisive (snippet format, PAA), ask
Marko to eyeball the live SERP; record what he reports.

## 1. SERP features present

- **Featured snippet?** Note format — paragraph / list / table — and the
  incumbent's exact answer. The page must provide a cleaner unit in the same
  format (the 40–60-word block for paragraph snippets; a tighter table for
  table snippets).
- **People Also Ask?** Every PAA question is a validated sub-query → H2 or
  FAQ entry, phrased as asked.
- **Image/video pack?** Signals visual intent — the hero SVG concept and OG
  image should serve it.
- **AI Overview present?** Note which pages it cites and what they share —
  extractable blocks, stats density, structure. Citation share is a KPI
  alongside rank.

## 2. Top-10 content type

Count what actually ranks: calculators, articles, data tables, maps,
category pages. **The dominant type is the format this query wants** — a
prose article will not beat a wall of calculators, and vice versa. Mixed
SERPs (tool + article split) usually mean a tool page with extensive prose
below — exactly the tool-page anatomy.

## 3. Intent classification

One of: informational / commercial / transactional / navigational — and one
sentence stating what the searcher wants to walk away with. Serve that, not
what we wish the query meant. Mismatch here is unrecoverable by quality.

## 4. Entity & coverage extraction

List the sub-topics, entities, and terms the top pages collectively cover —
the completeness set. Cross-reference the deep-dive's H2/tertiary plan:
demand data orders the sections, the entity set fills coverage gaps. Both
feed fan-out coverage (AI Mode synthesizes across sub-queries).

## 5. The information-gain wedge

Name the one thing no top-10 page has that this page will: a computed
number, a primary-source chart, a working tool, fresher data, a
granularity nobody offers. If no wedge can be named, the page is not ready
to build — go back to the data or the angle. "Same as the SERP but longer"
is not a wedge.

## 6. Record it

Write the findings into the Phase 2 spec (features to contest, format,
intent sentence, entity gaps, the wedge). SERP decisions recorded once are
not re-litigated at build time.
